# Визитка на нативном WebGL

Самостоятельная версия rozhdestvenskiy.ru. Название директории соответствует
рендереру: настоящий WebGL, GLSL-шейдеры и объёмная геометрия, без Three.js,
React, runtime-зависимостей и CDN. Для production есть отдельная сборка. Основной проект в корне не меняется.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory webgl
```

Открыть http://127.0.0.1:8080. Исходникам с ES-модулями нужен HTTP-сервер.

## Production-сборка

```sh
cd webgl
npm ci
npm run build
```

Результат — `webgl/dist/index.html`: JavaScript, CSS, Onest WOFF2, SVG-логотипы и обе PNG-
фавиконки встроены. Код собирается esbuild, HTML минифицируется; внешних ресурсов
нет. Рядом генерируются побайтно проверенные `index.html.gz` (уровень 9) и
`index.html.br` (Brotli 11). Это сжатые представления того же единственного HTML.

На сервер загружаются все три файла. Конфигурация nginx выбирает Brotli/gzip
по `Accept-Encoding`, возвращает правильный `Content-Encoding` и `Vary`,
а HTML отправляется с `Cache-Control: no-cache`. Корневой старый проект
и его сборка не используются. Публикация и откат описаны в `DEPLOYMENT.md`.

## Поведение

- Композиция оригинала: металлическая карточка, RU/EN снизу слева,
  Telegram снизу справа. Дополнительных панелей нет.
- Серебристый сатинированный металл с тёмным текстом: мягкое округлое отражение, приглушённая
  середина блика, тонкая шлифовка и более яркие геометрические фаски.
- При каждом открытии меняются начальный наклон, фазы и небольшие амплитуды
  автодвижения, положение и траектория света. Случайные параметры выбираются
  один раз: при resize и восстановлении WebGL композиция не перескакивает.
- Фон — полная тёмная голубо-фиолетовая заливка без пятна. Яркость мягко
  «дышит» с циклом 18 секунд; слабый цветной отсвет на торце меняется синхронно.
- Глубину создают широкая подсветка за карточкой, затемнение по краям
  и рассеянная тень на заднем плане. Положение и размер тени учитывают
  реальный поворот и смещение карточки относительно верхнего левого света;
  это размытая проекция округлого контура карточки, без отдельного WebGL-прохода.
- Основной широкий источник света движется по объёмной траектории сверху слева
  с циклом 14–20 секунд. Освещение, металлический блик и тень следуют за
  одним источником; движение света останавливается при reduced motion.
- Переворот занимает 1.65 секунды, с плавным разгоном и остановкой. Наклон
  от указателя применяется отдельно в экранных осях и одинаков на обеих сторонах.
- Текст выровнен по видимой границе глифов. Основной текст и ссылки контрастные,
  монохромные; наведение подчёркивает ссылку в WebGL без пересоздания текстуры.
  Линия расположена ниже выносных элементов букв и сглаживается в экранных пикселях.
- Шрифт Onest: имя 500, остальной текст 400. В портретной раскладке логотип,
  имя и контакты выровнены слева; имя 24 px и должность набраны в две строки.
  Почта и Telegram — 12.5 px с интервалом 22 px.
  Портретная карточка имеет компактные пропорции 300×460: после удаления
  строки сайта в ней меньше пустого металла, при том же экранном размере текста.
  Блок выравнивается по вертикали от верха логотипа до последней строки Telegram.
- Клик или тап переворачивает карточку только внутри её реального
  округлого контура с учётом текущего поворота и масштаба. Клик/тап по фону
  плавно сбрасывает наклон и масштаб, сохраняя язык. Попадание фиксируется
  при начале касания; жест, начатый на фоне, не вращает карточку. Ссылки внутри карточки кликабельны:
  пересечение луча с плоскостью учитывает поворот и масштаб.
- При наведении ближайший к курсору край слегка приподнимается к зрителю.
  Перетаскивание задаёт
  угол, который сохраняется после отпускания; дальнейшее наведение добавляет
  небольшой наклон относительно этой позиции. Автопокачивание затихает
  при ручном управлении и плавно возвращается через 1.4 секунды без ввода. Escape возвращает карточку в исходную позицию.
- В покое разные по частоте плавные колебания X/Y/Z и вертикальное парение
  сохраняют заметное движение даже рядом с разворотом одной из осей. На
  телефоне амплитуда ограничена с учётом краёв экрана и нижних элементов.
- Карточка — жёсткая плоская пластина. Курсор приподнимает ближайший край
  поворотом вокруг центра: до 7° по X, 9° по Y и 0.7° по Z. Вся карточка
  не перемещается за курсором, поверхность и текст не деформируются.
- Наклон использует пружинное сглаживание с критическим затуханием:
  плавное ускорение и торможение без мгновенного разворота скорости.
- Во время переворота наклон зафиксирован; после завершения реакция на курсор
  возобновляется плавно. Колесо и pinch меняют масштаб (0.5–2.5).
- RU/EN синхронизированы с URL, историей, заголовком, языком документа и
  фавиконкой. RU-иконка взята с ya.ru, EN — с yandex.com.tr (см. assets/README.md).
- При фокусе на сцене Enter/Space переворачивают, стрелки наклоняют,
  `+`/`-` масштабируют, Escape сбрасывает масштаб и наклон.
- На десктопе: крупный логотип, имя, должность, отступ, почта и t.me/sbmaxx.
  Основной размер — примерно 760×420 CSS px (контакты около 18 px), независимо
  от размера достаточно большого окна. Фиксированная пиксельная перспектива
  сохраняет вид карточки и при наклоне. В узкой десктопной раскладке ширина
  ограничена 400 px. Если места не хватает, карточка вписывается в окно с
  запасом для покачивания и нижних элементов; ручной зум доступен отдельно.
  В обеих ориентациях и языках остаются только почта и t.me/sbmaxx.
  Физический адрес, телефон, адрес сайта и ссылки GitHub в интерфейсе убраны.
- В горизонтальном положении на тач-устройствах используется широкая раскладка:
  масштаб учитывает доступную высоту и оставляет место для нижних элементов.
- Tab/Shift+Tab обходят три ссылки активной стороны во всех раскладках (включая логотип). Фокус виден
  монохромной рамкой прямо на карточке, Enter сохраняет нативную активацию
  ссылки. Скрытая сторона исключена из Tab-порядка.
- Наведение на ссылку удерживает положение на 1.8 секунды после движения мыши,
  чтобы удобно кликнуть; затем покачивание возвращается даже под неподвижным
  курсором. Клавиатурный фокус удерживает позу до потери фокуса. Свет продолжает
  двигаться; наведение не добавляет угол автопокачивания в сохранённый наклон.
  Рамка пересчитывается при смене ориентации раскладки.
- `prefers-reduced-motion` отключает движение и непрерывную отрисовку.
- При потере WebGL-контекста показываются обычные HTML-контакты;
  после восстановления сцена создаётся заново. HTML доступен и без JavaScript.
- В HTML-режиме работают RU/EN и история, ссылки доступны с клавиатуры,
  колесо и жесты прокрутки не перехватываются. Без JavaScript видны обе стороны.
- HTML-карточки используют ту же типографику и серебристую палитру; нижние
  ссылки стоят в потоке страницы и не перекрывают прокручиваемые контакты.
- Во время загрузки модуля резервируется полноэкранная сцена, canvas
  раскрывается после первого готового кадра. Если модуль не загрузился
  за 8 секунд, открывается HTML-версия.

## Реализация и производительность

Варианты палитры доступны без дополнительных контролов на карточке:
`?finish=silver` (по умолчанию), `?finish=graphite`, `?finish=titanium`.
Меняются металл, торец, логотип и цвет текста. HTML-резервная версия остаётся
серебристой.

`renderer.js` содержит математику, геометрию, текстуры, освещение и hit testing.
`engraving.js` один раз при создании раскладки строит карту глубины и нормалей
для имени и логотипа; в кадрах анимации чтений canvas и загрузок текстур нет.
`app.js` управляет вводом и жизненным циклом. `data.js` содержит данные текстур
и пути логотипов. Доступный HTML-дубль контактов находится в `index.html`.
При изменении контактов обновлять и `data.js`, и HTML-дубль.

- Три draw call на кадр: лицевая сторона, оборот, торец.
- Освещение и отражение студийного источника рассчитываются одним шейдером.
  Это приближение металлического материала, а не точное воспроизведение PBR
  и bloom исходной Three.js-сцены.
- Нет полноэкранных постэффектов, environment map и внешних запросов.
- DPR ограничен 2; текстуры создаются только при смене ориентации карточки.
- Текстуры имеют mip-уровни с трилинейной фильтрацией и анизотропией до 8×,
  когда она доступна. Premultiplied alpha предотвращает ореолы у текста
  и логотипов при уменьшении и повороте под острым углом.
- В покое отрисовка ограничена 30 fps, при движении мыши, перевороте
  и перетаскивании — 60 fps. До завершения движения по инерции сохраняются 60 fps.
- Скрытая вкладка не запрашивает кадры; при reduced motion кадры нужны только
  при изменениях. Ресурсы старой геометрии/текстур удаляются при перестроении.

Это структурные улучшения; время GPU и расход батареи на реальных мобильных
устройствах отдельно не измерялись.

## Проверка

Браузерный сценарий использует установленный Chrome и внешний Playwright,
который не входит в зависимости этой версии:

```sh
npm install --prefix /tmp/ya-card-browser-check playwright
PLAYWRIGHT_MODULE=/tmp/ya-card-browser-check/node_modules/playwright/index.mjs \
  node webgl/test/browser.mjs
```

Предварительно запустить HTTP-сервер. Проверяются WebGL-отрисовка, языки и
история, клавиатура, drag/wheel/pinch, ссылки на вращаемой поверхности,
reduced motion, потеря/восстановление контекста, работа без JS/WebGL,
отсутствие CDN и отсутствие скроллбара при замедленной загрузке модулей.
Также проверяются отсутствие сброса наклона при клике и одинаковое направление
наклона обеих сторон в горизонтальной и вертикальной раскладках.
Отдельно проверяются сохранение ориентации после drag и отсутствие влияния
движения мыши на наклон в середине переворота.
Скриншоты сохраняются в `/tmp/ya-card-final-*.png`.

Проверка единого production-файла и опубликованного сайта:

```sh
ARTIFACT=1 CARD_URL=https://rozhdestvenskiy.ru/ \
  PLAYWRIGHT_MODULE=/tmp/ya-card-browser-check/node_modules/playwright/index.mjs \
  node webgl/test/browser.mjs
```

## Рельеф и safe area

Логотип монохромный, с тёмной металлической поверхностью и неглубокой выемкой;
имя с фамилией тоже гравированное. Должность и контакты плоские.
Из маски глифов вычисляется фаска: у имени 0.70 px шириной / 0.38 px глубиной,
у логотипа 1.20 / 0.72 px. На мобильной карточке фаска логотипа уменьшается
пропорционально его ширине. Карта RGBA хранит нормали, глубину и покрытие.
Полированная поверхность логотипа отражает тот же круглый источник, что и
сатинированная пластина, с более узким бликом; внутренняя фаска темнеет или
блестит согласно своей нормали. Яркая часть блика плавно сжимается без белого пересвета.
Микрошлифовка видна только при достаточном экранном размере, чтобы не мерцать.
Имя на десктопе — 22 px; его тёмное заполнение остаётся матовым.
UV-базис преобразуется отдельно для каждой стороны и ориентации.
На малом экранном размере и при остром угле эффект плавно ослабляется.
Контур букв не расширяется; внешней тени и белой обводки нет.
Обе текстуры имеют mipmaps/anisotropy. Геометрия карточки остаётся плоской.
Скруглённый торец использует плавные нормали, без отдельных световых граней.
По умолчанию используется `?study=sculpted`: более глубокая гравировка имени
и логотипа, выраженные внутренние фаски и движущийся полированный блик.
`?study=etched` сохраняет более плоскую обработку. `?study=milled` сохраняет
предыдущую обработку; предыдущий свет сохранён в `?study=cut`.
Для сравнения доступны `?study=emboss`
(выпуклый) и `?study=smoke` (более тёмный). Варианты первого прохода
`?study=satin`, `?study=inset`, `?study=polished` тоже сохранены.
Профиль пластины тоньше: полутолщина 0.022, фаска 0.008 в единицах сцены.
Для сравнения доступны `?edge=standard`, `?edge=soft`, `?proportion=tall`
и `?proportion=balanced`; на саму карточку элементы управления не добавляются.
Описание выбора и точки возврата — `design/2026-09-24-mobile-iterations.md`,
`design/2026-09-24-post-cleanup-goal.md`, `design/2026-09-24-material-round.md`
и `design/2026-09-24-visual-round.md`.

На touch-устройствах фон по верхнему и нижнему краям переходит в `#101722`,
совпадающий с фоном html/body и theme-color. Включён viewport-fit=cover;
RU/EN и социальные ссылки учитывают env(safe-area-inset-*).
Основание: [WebKit: safe areas](https://webkit.org/blog/7929/designing-websites-for-iphone-x/)
и [WebKit: theme-color](https://webkit.org/blog/11989/new-webkit-features-in-safari-15/).
Проверены мобильные CSS и WebGL в Chromium; системные панели Safari на физическом
устройстве в этой среде не проверялись.

Отдельная проверка гравировки (сама поднимает временный localhost-сервер):

```sh
PLAYWRIGHT_MODULE=/tmp/ya-card-browser-check/node_modules/playwright/index.mjs \
  node webgl/test/engraving.mjs
```

Проверяет знак глубины, нейтральную маску вне имени/логотипа, UV-базисы обеих
сторон, вклад нормалей в GPU-освещение, mipmaps и отсутствие генерации/загрузок
текстур во время кадров. Лицензия и происхождение шрифта — `assets/README.md`.

Контакты, фокус и fallback проверяются на собранном single-file artifact:

  node webgl/test/run-built-browser.mjs
PLAYWRIGHT_MODULE=/tmp/ya-card-browser-check/node_modules/playwright/index.mjs \
  node webgl/test/mobile-layout.mjs
PLAYWRIGHT_MODULE=/tmp/ya-card-browser-check/node_modules/playwright/index.mjs \

  node webgl/test/desktop-size.mjs
